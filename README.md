This is a repository which contains lab works done in my master's in Bicocca. The work is mostly about how neural networks may be applied to Ising model or different physics tasks. The main library used is Pytorch. Notebook files are mostly the assignments and .py are the solutions. 

Quick summary:

1) Two scripts contain simple neural networks for classification and regression using data for Ising model
   
2) Two scripts contain Physical Informed Neural Networks using data for Stoke's Law
3) Two scripts on unsupervised PINN - Shrodinger equation and Stoke's law
4) Two scripts for anomaly detection using PCA and autoencoder
